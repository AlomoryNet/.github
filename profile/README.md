## What We Do

AlomoryNet works across software design, implementation, and ongoing improvement. Areas of work include:

- **Mobile applications:** Flutter and Android application development.
- **Web applications:** Responsive web experiences and application interfaces.
- **Backend and APIs:** Application services, API development, and integrations.

## Products & Projects

### Net Test

A published Android application for evaluating internet connection quality. Net Test measures download speed, upload speed, ping, and jitter. It keeps test history locally on the device and can use location to select a nearby test server.

[**Get Net Test on Google Play**](https://play.google.com/store/apps/details?id=net.alomory.nettest) · [Support and policy repository](https://github.com/AlomoryNet/NetTest-Support)

### Crypta

A standalone file and document management project covering document capture, custom-form records, file and media management, server or cloud transfers, and PDF utilities.

[Source repository](https://github.com/AlomoryNet/Crypta)

### Yemen Real Estate Portal

A Flutter-based real-estate portal project focused on property discovery and management in Yemen. See the repository for its current implementation and feature status.

[Source repository](https://github.com/AlomoryNet/yemen-real)

> Net Test and Crypta are separate products with separate codebases. They are not components of one another.

## Technology

Technologies used across AlomoryNet projects include:

- **Mobile:** Flutter, Dart, and Android
- **Web and backend:** TypeScript, Node.js, Express, and web technologies
- **Data:** PostgreSQL, Drizzle ORM, Supabase, and Firebase in relevant projects
- **Engineering tools:** pnpm, Git, and esbuild

The technology stack varies by product; not every technology is used in every project.
